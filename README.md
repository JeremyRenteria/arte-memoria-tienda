# 🎨 Arte & Memoria - Tienda Online

E-commerce especializado en retablos artesanales, álbumes personalizados y fotografías artísticas.

## 🚀 Características

### Frontend (React + Vite)
- ⚡ **Interfaz moderna y responsive**
- 🔐 **Sistema de autenticación**
- 🛒 **Carrito de compras y pedidos**
- 📱 **Diseño mobile-first**

### Backend (Node.js + Express + MongoDB)
- 🔒 **Autenticación JWT**
- 🗄️ **API RESTful**
- 📊 **Gestión de pedidos y usuarios**
- 🛡️ **Middleware de seguridad**

## 🛠️ Tecnologías

### Frontend
- React 18
- Vite
- React Router DOM
- Context API
- CSS3

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt
